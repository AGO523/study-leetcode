# 🔗 リンクリストとは？＋反転問題の解説

---

## ✅ リンクリストとは？

**リンクリスト（Linked List）** は、次のノードを**ポインタ（参照）**でつなぐことで、データを順に並べたデータ構造です。

### 🔸 基本構造（単方向リンクリスト）

```
[1] -> [2] -> [3] -> nil
```

各ノード（ListNode）は、

- 値（val）
- 次のノードへの参照（next）

を持っています。

### 🧱 Ruby でのノード定義

```ruby
class ListNode
  attr_accessor :val, :next

  def initialize(val = 0, _next = nil)
    @val = val
    @next = _next
  end
end
```

---

## 📘 なぜ配列ではなくリンクリスト？

| 特徴             | 配列        | リンクリスト                  |
| ---------------- | ----------- | ----------------------------- |
| メモリ配置       | 連続        | バラバラでも OK               |
| 要素の追加・削除 | 遅い (O(n)) | 速い (O(1))（場所がわかれば） |
| 要素のアクセス   | 速い (O(1)) | 遅い (O(n))                   |

## 💡 今日の問題：リンクリストを反転する

### 🔍 問題文（日本語）

単方向リンクリストの `head` が与えられます。  
このリストを**逆順（反転）**し、新しい先頭ノードを返してください。

---

### 🧪 例

| 入力              | 出力              |
| ----------------- | ----------------- |
| `[1, 2, 3, 4, 5]` | `[5, 4, 3, 2, 1]` |
| `[1, 2]`          | `[2, 1]`          |
| `[]`              | `[]`              |

---

## 🧠 解き方（アルゴリズム）

リンクリストの向きを一つずつ逆にしていきます。

### 🔄 反転のイメージ

```
元:    1 -> 2 -> 3 -> 4 -> 5 -> nil
反転後: nil <- 1 <- 2 <- 3 <- 4 <- 5
```

### 🔧 手順（3 つのポインタを使う）

1. `prev`：前のノード（初期は `nil`）
2. `curr`：現在のノード（初期は `head`）
3. `next_node`：次のノード（現在の `.next` を一時保存）

---

## ✅ Ruby での実装（コメント付き）

```ruby
def reverse_list(head)
  prev = nil      # 1つ前のノード（初期は nil）
  curr = head     # 現在のノード

  while curr
    next_node = curr.next  # 次のノードを一時保存
    curr.next = prev       # 向きを逆にする
    prev = curr            # prev を一つ進める
    curr = next_node       # curr も進める
  end

  prev  # 最後に残ったノードが新しい先頭
end
```

---

## 🔁 入出力の補足

```ruby
# 入力 [1,2,3]
n3 = ListNode.new(3)
n2 = ListNode.new(2, n3)
n1 = ListNode.new(1, n2)

reversed = reverse_list(n1)

# 出力を配列に変換して表示
def to_array(head)
  result = []
  while head
    result << head.val
    head = head.next
  end
  result
end

puts to_array(reversed).inspect  # => [3,2,1]
```

## 🧩 総まとめ

| 内容               | 説明                                                              |
| ------------------ | ----------------------------------------------------------------- |
| リンクリストとは？ | ノード同士が next でつながる構造                                  |
| なぜ使う？         | メモリ効率、柔軟な挿入削除が可能                                  |
| 反転するには？     | 3 つのポインタ（prev, curr, next_node）を使って一つずつ向きを逆に |
| 時間計算量         | O(n)                                                              |
| 空間計算量         | O(1)（追加メモリ不要）                                            |
